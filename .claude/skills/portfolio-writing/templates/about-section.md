# About section

Write in first person, present tense. The goal is a specific person a
reader could recognize again, not a résumé summarized into prose.

## Shape

1. **What you do now** — one sentence, concrete (see hero-headline.md
   for the same discipline applied to a longer sentence).
2. **How you got here / what you've actually shipped** — 2-3 sentences,
   real specifics (a company, a scale, a hard problem), not a list of
   adjectives about your character.
3. **What you care about or do outside work** (optional, 1 sentence) —
   only include if it's true and specific. A generic "I love learning
   new things" line is worse than omitting it.

## Do

- Use real specifics: a number, a company/project name, a technology
  you can talk about for ten minutes.
- Write sentences you'd actually say out loud to a colleague.
- Let one honest limitation or preference show ("I'd rather ship a
  smaller thing correctly than a big thing fast") — specificity reads
  as authentic; a list of universal virtues reads as generated.

## Don't

- Don't list personality traits as adjectives ("I'm a passionate,
  detail-oriented, results-driven professional"). Show it through what
  you did instead.
- Don't claim you're "always learning" or "constantly innovating"
  without naming the actual thing you're currently learning.
- Don't write in third person about yourself ("Alvaro is a developer
  who...") unless the whole site's voice is consistently third-person —
  pick one and stay consistent across every page.

## Example rewrite

> Generic: "I'm a passionate full-stack developer with a love for
> clean code and innovative solutions, always eager to learn new
> technologies and tackle exciting challenges."

> Specific: "I've spent the last four years building backend systems
> for small e-commerce teams — mostly Node and Postgres, mostly fixing
> the thing that breaks under Black Friday traffic. Right now I'm
> digging into Rust for a side project that parses shipping-label
> data faster than the Python version it replaced."
